展開・因数分解・不等式

二乗の展開
(a ± b)² = a² ± 2ab + b²
(a + b)(a − b) = a² − b²
(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca
三乗の展開
(a ± b)³ = a³ ± 3a²b + 3ab² ± b³
a³ ± b³ = (a ± b)(a² ∓ ab + b²)
a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
たすき掛け
acx² + (ad + bc)x + bd = (ax + b)(cx + d)
二項定理
(a + b)n = Σr=0n nCr an−r br

一般項は nCr an−rbr。a = b = 1 とすれば ΣnCr = 2n、a = 1, b = −1 とすれば交代和が 0 になる。

多項定理
(a + b + c)n の apbqcr の係数 = n!p! q! r!

p + q + r = n。

絶対値
|x| < a ⇔ −a < x < a|x| > a ⇔ x < −a または a < x
|a| − |b| ≦ |a + b| ≦ |a| + |b|

a > 0 とする。三角不等式の等号は ab ≧ 0 のとき。

相加相乗平均
a + b2 ≧ √aba + b + c3 ≧ 3√abc

a, b, c > 0。等号成立は a = b（三変数では a = b = c）のとき。最小値を問う問題で頻出。

コーシー・シュワルツ
の不等式
(a² + b²)(x² + y²) ≧ (ax + by)²

等号成立は ay = bx のとき。一般に (Σak²)(Σbk²) ≧ (Σakbk)²。

恒等式
ax² + bx + c = 0 がすべての x で成立 ⇔ a = b = c = 0

係数比較法、または数値代入法（代入後は十分性の確認が必要）。

二次関数と二次方程式

平方完成
y = ax² + bx + c = a(x + b2a)² − b² − 4ac4a

頂点 (−b/2a, −(b²−4ac)/4a)、軸は x = −b/2a。

解の公式
x = −b ± √b² − 4ac2ab = 2b′ のとき　x = −b′ ± √b′² − aca
判別式
D = b² − 4ac

D > 0 で異なる二実数解、D = 0 で重解、D < 0 で異なる二虚数解。x 軸との共有点の個数に対応する。

解の存在範囲
f(x) = ax² + bx + c (a > 0) の 2 解がともに正 ⇔ D ≧ 0 かつ 軸 > 0 かつ f(0) > 0

判別式・軸の位置・端点の符号の 3 条件で捉える。区間 (p, q) に 1 解のみなら f(p)f(q) < 0。

最大・最小
定義域 p ≦ x ≦ q の二次関数は、軸の位置と区間の位置関係で場合分け

軸が区間内か、左外か、右外かの 3 通り。最大値は区間の両端で比較する。

解と係数の関係・高次方程式

解と係数の関係
（二次）
ax² + bx + c = 0 の解を s₁, s₂ とすると
s₁ + s₂ = −bas₁s₂ = ca

逆に、和が p、積が q である 2 数を解にもつ二次方程式は x² − px + q = 0。

解と係数の関係
（三次）
ax³ + bx² + cx + d = 0 の解を s₁, s₂, s₃ とすると
s₁ + s₂ + s₃ = −bas₁s₂ + s₂s₃ + s₃s₁ = cas₁s₂s₃ = −da

符号は −, +, − と交互になる。四次以降も同様に交代する（ヴィエトの公式）。

対称式の変形
s₁² + s₂² = (s₁ + s₂)² − 2s₁s₂
s₁³ + s₂³ = (s₁ + s₂)³ − 3s₁s₂(s₁ + s₂)
(s₁ − s₂)² = (s₁ + s₂)² − 4s₁s₂ = Da²
1s₁ + 1s₂ = s₁ + s₂s₁s₂

三変数では s₁² + s₂² + s₃² = (s₁+s₂+s₃)² − 2(s₁s₂+s₂s₃+s₃s₁)。

剰余定理・因数定理
P(x) を x − k で割った余りは P(k)
P(k) = 0 ⇔ P(x) は x − k を因数にもつ

ax − b で割った余りは P(b/a)。二次式で割った余りは一次以下なので px + q とおいて連立させる。

有理数解の候補
整数係数の anxn + … + a₀ = 0 の有理数解は　x = ±a₀ の約数an の約数

因数定理を使う際、代入すべき値を絞り込むために用いる。

虚数解の性質
実数係数の方程式が s₁ = p + qi を解にもつ ⇒ s₁ = p − qi も解

共役複素数は必ず対で現れる。ゆえに奇数次方程式は少なくとも 1 つの実数解をもつ。

1 の三乗根 ω
ω³ = 1ω² + ω + 1 = 0ω = −1 ± √3 i2

x³ = 1 の虚数解。次数下げに用いる。

複素数の計算
z = a + bi のとき　z = a − bizz = a² + b² = |z|²
z + z = 2a（実数）z − z = 2bi（純虚数）

z が実数 ⇔ z = z、z が純虚数 ⇔ z = −z かつ z ≠ 0。

点と直線

2 点間の距離
AB = √(x₂ − x₁)² + (y₂ − y₁)²

空間では √(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²。

m : n に外分　( −nx₁ + mx₂m − n , −ny₁ + my₂m − n )

外分は n を −n に置き換えたもの。

d = |ax₁ + by₁ + c|√a² + b²

点 (x₁, y₁) と直線 ax + by + c = 0 の距離。原点からなら |c| / √(a²+b²)。空間の平面 ax+by+cz+d = 0 でも同型で |ax₁+by₁+cz₁+d| / √(a²+b²+c²)。

（座標）
S = 12 |x₁y₂ − x₂y₁|

O(0,0), A(x₁,y₁), B(x₂,y₂) の場合。一般の 3 点なら 1 点を原点に平行移動して適用する。

直線束
(a₁x + b₁y + c₁) + k(a₂x + b₂y + c₂) = 0

2 直線の交点を通る直線の全体（ただし 2 本目自身を除く）。交点を求めずに済む。

円

円の方程式
(x − p)² + (y − q)² = r²
x² + y² + lx + my + n = 0 　⇔　中心 (−l2, −m2)、半径 √l² + m²4 − n

半径が実数であるためには l² + m² − 4n > 0 が必要。

円の接線
x² + y² = r² 上の点 (x₁, y₁) で　x₁x + y₁y = r²
(x−p)² + (y−q)² = r² 上の点で　(x₁−p)(x−p) + (y₁−q)(y−q) = r²

円外の点から引く接線は、中心と直線の距離 = 半径 の条件で求める。

円と直線の位置関係
中心と直線の距離 d、半径 r
d < r 　2 点で交わるd = r 　接するd > r 　共有点なし

弦の長さは 2√(r² − d²)。判別式でも判定できるが、距離公式の方が計算が軽い。

2 円の位置関係
中心間距離 d、半径 r₁ > r₂
d > r₁ + r₂ 離れるd = r₁ + r₂ 外接r₁ − r₂ < d < r₁ + r₂ 交わる
d = r₁ − r₂ 内接d < r₁ − r₂ 内包
2 円の交点を通る図形
C₁ + kC₂ = 0

C₁, C₂ を「= 0」の形にした円の式とする。k = −1 のとき二次の項が消え、2 交点を通る直線（共通弦）の式になる。

軌跡と領域
y > f(x) は曲線の上側、y < f(x) は下側
(x−p)² + (y−q)² < r² は円の内部

軌跡は、動点を (x, y) とおき媒介変数を消去する。得られた図形が条件を満たすかの逆の確認を忘れないこと。アポロニウスの円は AP : BP = m : n の軌跡。

重心は中線を 2 : 1 に内分する
